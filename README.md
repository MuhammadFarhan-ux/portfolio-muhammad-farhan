## 🎨 Key Features & Highlights

- **Auto Dark / Light Theme Detection**: Automatically detects user's device/OS theme preference (`prefers-color-scheme`), adapts in real-time on system change, and provides a manual navbar moon/sun toggle.
- **Glowing Cyan Hexagon Frame**: Custom polygon clip-path framing Muhammad Farhan's portrait photo with diffuse radial cyan lighting.
- **Direct Email & 1-Click Copy**: Official email **`syedfarhansaif@gmail.com`** integrated across all pages with toast alert feedback.
- **Three.js 3D WebGL Engine**: 800+ ambient cyan and emerald particles with dynamic camera parallax tracking mouse movement.
- **Zero Build Dependencies**: Pure HTML5, CSS3, JavaScript (ES6+), and Three.js via CDN. Runs directly by opening any `.html` file.
